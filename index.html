Install in Chrome or Edge

This is a manual install, not a Chrome Web Store listing.

  1. 1

    Download the ZIP and unzip it.

  2. 2

    Open chrome://extensions or edge://extensions.

  3. 3

    Turn on Developer mode, then choose Load unpacked.

  4. 4

    Select the unzipped extension folder. Pin Multiedit, then open it on a page with text fields.

Works with ordinary text inputs and textareas. Rich text editors, password fields, and browser settings pages are not supported. Some websites may handle edits differently or autosave as soon as a field changes. Undo is available only in the current panel session and cannot reverse a website’s autosave.
